# User Guide

## Purpose
A simple, step-by-step guide for everyday users — no technical knowledge needed.

## Overview
Two ways to use the system: the **Telegram bot** (fastest — just send a photo) and the **web dashboard** (viewing, reporting, exporting). Business users have roles: **admin** (sees everything) and **clerk** (sees their own branch).

## Part 1 — Telegram bot

**Log a receipt:** send a photo → the bot reads it and replies with the details. If unsure of the category, it asks you to pick (or "Others" + a short note). Send **several photos at once**, or a **PDF** — same result.

| Menu button | What you get |
|---|---|
| 📋 Today Bills | Everything captured today |
| 💰 Today Expenses | Today's total |
| 📅 Weekly Record | This week's total |
| 🧭 Bot Guide | Quick help |

**Delete a bill:** Personal — tap ❌ next to it in Today Bills. Business — tap **🗑️ Delete a bill**, then reply with the bill's number (only your own bills).

**Business extra:** after sending a receipt, tap which staff member it belongs to; Today Bills then shows the staff name on each line.

## Part 2 — Web dashboard

**Log in:** Personal — access token. Business — username + password.

| Action | How |
|---|---|
| See expenses | Listed on the main screen; filters to narrow down |
| Fix a detail | Click and edit (a category fix is remembered) |
| Remove one | Delete — hidden but recoverable |
| Totals & charts | Overview/Reports section |
| Ask a question | AI assistant, e.g. "How much on fuel this month?" |
| Export | Excel download |
| Bulk add | Upload area for many receipts at once |

**Business admin extras**
| Action | Who | What |
|---|---|---|
| Add branches & staff | Admin | Set up offices and people |
| Review flagged bills | Admin | Approve or reject |
| Set monthly petty-cash float | Admin | Opening cash per branch |
| Send to Admin | Clerk | Submit branch's month |
| Monthly statement | Admin | Download petty-cash statement (Excel/PDF) with receipts |

## Notes
- Records are saved before any summary is shown — a quiet bot doesn't mean lost data.
- Dates use Malaysia time (UTC+8).
